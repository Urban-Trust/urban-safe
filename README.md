# 🌆 Urban Safe

**Urban Safe** es una aplicación enfocada en la **seguridad ciudadana**, diseñada para que los vecinos puedan **reportar incidentes**, **visualizar alertas** y **mantenerse informados** sobre los sucesos que ocurren cerca de su zona, todo desde una plataforma interactiva y colaborativa.

---

## 🚀 Objetivo
Brindar una herramienta tecnológica que fomente la **participación ciudadana** y mejore la **comunicación entre vecinos y autoridades locales**, permitiendo una respuesta más rápida ante situaciones de riesgo o emergencia.

---

## 🧭 Características principales
- 📍 **Mapa interactivo:** muestra incidentes recientes y alertas geolocalizadas.  
- 📝 **Reportes guiados:** formulario paso a paso para registrar incidentes con ubicación automática.  
- 🔔 **Notificaciones de alerta:** avisos inmediatos ante nuevos incidentes cercanos.  
- 👥 **Canales activos:** comunicación entre usuarios sobre temas de seguridad o ayuda vecinal.  
- 🌐 **Versión web y móvil:** interfaz adaptable con diseño enfocado en accesibilidad y usabilidad.
